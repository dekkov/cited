# Sponsoring Cited

Cited is a solo-maintained open-source project with no VC funding and no paid tiers. Sponsorship directly covers hosting and LLM API costs, and unlocks dedicated maintainer time.

## Why Sponsor

- **No VC, no paid tiers** — sustainability depends on community support
- **Transparent burn rate** — costs are published publicly once the hosted demo launches (Phase 4)
- **Direct impact** — your sponsorship keeps the hosted demo running and pays for LLM inference on clip extraction
